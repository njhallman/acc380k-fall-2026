# Demo: a random forest that writes stories

A language model predicts the next word, appends it, and repeats. This notebook builds that loop with a random forest trained on children's stories, then uses a temperature setting to make the stories vary.

[Open in Colab](https://colab.research.google.com/github/njhallman/acc380k-fall-2026/blob/main/notebooks/demo-next-word-forest/demo.ipynb)

Run the cells from top to bottom. A full run takes a few minutes.
