# Demo: classifying 10-K passages with an AI model

Pull text from a 10-K the way you did in Homework 3, then send each passage to a classification model (Jev) and collect its labels in a DataFrame.

[Open in Colab](https://colab.research.google.com/github/njhallman/acc380k-fall-2026/blob/main/notebooks/demo-llm-classify/demo.ipynb)

Your instructor will give you the class key in class. Put it and your UT EID in the setup cell. Each EID has a small usage budget.
